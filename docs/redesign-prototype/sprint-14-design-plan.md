# Early Sprint 14 proposals — 18 October 2026

The user requested seeing potential directions now, before unattended execution.
This is an explicitly requested early proposal, not production interface work or
satisfaction of Sprint 14 entry gates. Resolve Sprint 7.5 before implementation.

Audience/job: Singapore investors inspecting historical returns and maintaining
local ledgers. Preserve four destinations, request context and factual warnings.
No promotional hero, eyebrows, decorative numbering or unexplained metadata.

Research: base #F5F6FA, surface #FFFFFF, text #24242D, muted #626473,
structural line #DCDDE6, action/series #5140A0. IBM Plex Sans for controls/data
with tabular numerals; no monospace microtype. A compact horizontal workspace
header; fixed-width setup alongside a result and a genuinely labeled price
chart. Left-aligned task names and right-aligned financial values.

    brand | Simulator  Compare  Portfolio  Data & methods
    Investment simulator
    setup (280px) | selected investment / result / price history

Focus: base #F3F6F6, surface #FFFFFF, text #183031, muted #526A6B,
structural line #D2DEDD, action/series #006D69. Public Sans, intentionally plain
labels and an airy but compact type scale. Quiet workspace rail; horizontal
setup band; full-width financial output with secondary figures in a vertical
balance-style list. Mobile folds rail into navigation and vertically stacks.

    workspace rail | Investment simulator
                   | security / amount / dates / calculate
                   | value + contextual figures / price history

Self-critique: removed decorative brand symbol, tinted dark form panel, acid-green
CTA, all-caps meta strips, oversized marketing intro and identical metric cards.
Both use actual committed QQQ example data (not invented returns). Research is
recommended for repeated analysis: the setup stays visible next to its output.
Focus has more room for tables and future portfolio transaction editing. These
are visual previews; financial interaction is deliberately limited to view mode.


Product Owner feedback: both directions acceptable; muted colour is not a
blocker. Use recommended Research as the working reference and refine accent
strength during Sprint 14. Technical recovery comes first. This is early
proposal feedback, not acceptance of an integrated implementation.
